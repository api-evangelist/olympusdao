# OlympusDAO

OlympusDAO is a decentralized reserve currency protocol on Ethereum that pioneered protocol-owned liquidity (POL). The protocol issues OHM, backed by a diversified on-chain treasury spanning Ethereum, Arbitrum, Base, Polygon, Fantom, and Berachain.

## APIs

| API | Base URL | Description |
|-----|----------|-------------|
| Protocol Metrics API | `https://treasury-subgraph-api.olympusdao.finance` | Daily OHM supply, treasury assets, protocol metrics |
| Circulating Supply API | `https://circulating-supply.api.olympusdao.finance` | OHM circulating supply (plain text) |
| Total Supply API | `https://total-supply.api.olympusdao.finance` | OHM total supply (plain text) |
